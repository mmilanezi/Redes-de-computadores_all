1. CÓDIGOS DE LINHA (banda base)
==============================================================================
  Sequência: 1011000001101001 (16 bits, 7 uns e 9 zeros), V = 1 V

  NRZ unipolar  bit 0 -> 0 V                 bit 1 -> +V
  NRZ polar     bit 0 -> -V                  bit 1 -> +V
  Manchester    bit 0 -> ↓ no meio do bit    bit 1 -> ↑ no meio do bit
  (↑ = subida de -V para +V; ↓ = descida de +V para -V)

  bit              1   0   1   1   0   0   0   0   0   1   1   0   1   0   0   1
  NRZ unipolar    +V   0  +V  +V   0   0   0   0   0  +V  +V   0  +V   0   0  +V
  NRZ polar       +V  -V  +V  +V  -V  -V  -V  -V  -V  +V  +V  -V  +V  -V  -V  +V
  Manchester       ↑   ↓   ↑   ↑   ↓   ↓   ↓   ↓   ↓   ↑   ↑   ↓   ↑   ↓   ↓   ↑

  código         transições   maior trecho sem transição   nível médio (DC)
  NRZ unipolar            8                     5,0 bits            0,438 V
  NRZ polar               8                     5,0 bits           -0,125 V
  Manchester             23                     1,0 bits            0,000 V

2. MODULAÇÕES DIGITAIS (ASK, FSK e BPSK)
==============================================================================
  Parâmetros:
    taxa de bits         Rb = 1.000 bit/s (Tb = 1 ms)
    portadora            fc = 2.000 Hz (2 ciclos por bit)
    FSK                  f0 = 2.000 Hz, f1 = 4.000 Hz
    amplitude            A = 1 V
    amostragem           fs = 100.000 Hz (100 amostras por bit)
    portadora            e(t) = A·sen(2π·f·t + θ)

  ASK           bit 0 -> amplitude 0         bit 1 -> amplitude A
  FSK           bit 0 -> f0 = 2 kHz          bit 1 -> f1 = 4 kHz
  BPSK          bit 0 -> fase 180°           bit 1 -> fase 0°

  bit               1    0    1    1    0    0    0    0    0    1    1    0    1    0    0    1
  ASK               A    0    A    A    0    0    0    0    0    A    A    0    A    0    0    A
  FSK              4k   2k   4k   4k   2k   2k   2k   2k   2k   4k   4k   2k   4k   2k   2k   4k
  BPSK             0° 180°   0°   0° 180° 180° 180° 180° 180°   0°   0° 180°   0° 180° 180°   0°
  (ASK: amplitude; FSK: frequência em kHz; BPSK: fase)
